1.0.0

First release

  • Quick notes in a panel beside any page, opened from the toolbar icon, the keyboard shortcut Alt+Shift+N or an optional button on the page.
  • Save selected text, links and whole pages from the right-click menu. Links, bold, lists and code are kept, along with the page they came from.
  • Search that ignores accents, forgives a one-letter typo and lists tag and title matches first. Filter to the notes saved from one website.
  • Pin, tag, clear with Undo, and a Trash that keeps cleared notes for 30 days.
  • Export a full backup or a Markdown file at any time.
  • A first-run guide, and a Check it yourself section in Settings that shows what Holdpad has been allowed to do, read live from your browser.
  • Light, dark and six colour palettes, in 8 languages: English, Hindi, Spanish, Portuguese (Brazil), German, French, Indonesian and Japanese.
  • Everything stays on your device. Holdpad has no network access, no account and no analytics.
