# Holdpad — fiche Chrome Web Store (français)

**Titre** (53/75)

Holdpad – Notes rapides et bloc-notes pour toute page

**Résumé** (124/132)

Notes rapides dans un panneau latéral, sur toute page. Gardez texte et liens, cherchez tout. Privé, hors ligne, sans compte.

---

**Description**

Holdpad est un panneau de notes rapides qui s'ouvre à côté de n'importe quelle page web. Notez une idée, gardez un passage que vous lisez ou un lien pour plus tard — sans quitter l'onglet, sans compte, et sans que rien ne quitte votre ordinateur.

Un bloc-notes pour ce dont vous avez besoin maintenant : le numéro d'un chat d'assistance, trois citations pour un devoir, le message d'erreur que vous allez chercher, la liste de courses pour tout à l'heure. Épinglez l'essentiel, effacez le reste une fois la tâche finie.

CE QUE VOUS POUVEZ FAIRE

• Notes rapides sur toute page — Alt+Maj+N ou l'icône, tapez, puis Ctrl/Cmd+Entrée.
• Gardez le texte sélectionné de n'importe quel site — sélectionnez, clic droit, « Enregistrer la sélection dans Holdpad ». Liens, gras, listes et blocs de code sont conservés, avec la page d'origine.
• Gardez liens et pages entières d'un clic droit.
• Bloc-notes riche — titres, listes, cases à cocher, citations, liens et blocs de code. Raccourcis Markdown à la frappe : « - » pour une liste, « # » pour un titre.
• Recherche instantanée — Ctrl/Cmd+K cherche dans le texte, les pages d'origine et les tags, avec surlignage.
• Épingles et tags — l'épinglé reste ; un tag par note, filtre en un clic.
• Vue liste ou vue cartes.
• Effacez sans crainte — une note ou toutes les notes non épinglées. Annulation immédiate, et la corbeille garde tout 30 jours.
• Partout dans Chrome — à côté de la page sur les sites, en fenêtre contextuelle sur les pages de Chrome.
• Bouton d'ouverture rapide optionnel dans le coin de chaque page, désactivé tant que vous ne l'activez pas.
• Exportez à tout moment — une sauvegarde restaurable ou un fichier Markdown lisible.
• À votre goût — thème clair, sombre ou système, six palettes, couleurs d'accent, police sans, serif ou mono.

PRIVÉ PAR CONCEPTION

• Vos notes restent sur cet appareil, dans le stockage local de Chrome.
• Pas de compte, pas d'inscription, pas de cloud, pas de pub, pas d'analytique.
• L'extension n'a aucun accès réseau : elle ne peut envoyer vos notes nulle part.
• Aucun accès à vos sites à l'installation. Le bouton optionnel ne le demande que si vous l'activez.

POUR COMMENCER

1. Épinglez Holdpad à la barre d'outils (icône puzzle → épingler).
2. Cliquez sur l'icône ou appuyez sur Alt+Maj+N sur n'importe quelle page.
3. Tapez une note puis Ctrl/Cmd+Entrée — ou sélectionnez du texte, clic droit, « Enregistrer la sélection dans Holdpad ».
