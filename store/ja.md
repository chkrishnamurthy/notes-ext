# Holdpad — Chrome ウェブストア掲載文（日本語）

**タイトル**（30/75）

Holdpad – どのページでも使えるクイックメモ＆メモ帳

**概要**（61/132）

どのページでもサイドパネルですばやくメモ。選択したテキストやリンクを保存して全文検索。プライベート、オフライン、登録不要。

---

**説明**

Holdpad は、どのウェブページの横にも開けるクイックメモのパネルです。思いついたことを書き留めたり、読んでいる文章やあとで見たいリンクを保存したり。タブを離れる必要も、アカウントも要りません。データがパソコンの外に出ることもありません。

「今」必要なもののためのメモ帳です。サポートチャットで聞いた電話番号、レポートに使う引用、これから検索するエラーメッセージ、1時間後に使う買い物リスト。大事なものはピン留めし、終わったら残りを片付けましょう。

できること

• どのページでもクイックメモ — Alt+Shift+N かアイコンで開き、入力して Ctrl/Cmd+Enter。
• どのサイトのテキストも保存 — 選択して右クリック →「選択範囲を Holdpad に保存」。リンク、太字、リスト、コードブロックも元のページ情報と一緒に残ります。
• リンクやページ全体も右クリックで保存。
• 書式付きメモ帳 — 見出し、箇条書き、チェックリスト、引用、リンク、コードブロック。入力中の Markdown ショートカット：「- 」でリスト、「# 」で見出し。
• すぐに検索 — Ctrl/Cmd+K で本文、保存元ページ、タグを検索し、一致箇所をハイライト。
• ピン留めとタグ — ピン留めしたメモは残ります。メモごとにタグを1つ、クリックで絞り込み。
• リスト表示とカード表示。
• 安心して片付け — 1件ずつでも、ピン留め以外をまとめてでも。すぐに元に戻せ、ゴミ箱に30日間残ります。
• Chrome のどこでも — 通常のサイトではページの横に、Chrome 自身のページではポップアップで開きます。
• 各ページの隅に置けるクイック起動ボタン（オプション、初期設定はオフ）。
• いつでもエクスポート — 復元できるバックアップ、または読みやすい Markdown ファイル1つ。
• 好みに合わせて — ライト・ダーク・システムのテーマ、6種類のカラーパレット、アクセントカラー、ゴシック・明朝・等幅フォント。

最初からプライベート

• メモはこの端末の Chrome ローカルストレージにだけ保存されます。
• アカウント、登録、クラウド、広告、解析はいずれもありません。
• 拡張機能にはネットワークへのアクセスが一切なく、メモをどこにも送信できません。
• インストール時にサイトへのアクセス権は不要。オプションのボタンは、オンにしたときだけ権限を求めます。

はじめかた

1. Holdpad をツールバーに固定（パズルのアイコン → 固定）。
2. どのページでもアイコンをクリックするか Alt+Shift+N を押す。
3. メモを入力して Ctrl/Cmd+Enter。またはテキストを選択して右クリック →「選択範囲を Holdpad に保存」。
